# Identité TheMadDoG.tmdg

Ce répertoire contient des illustrations vectorielles originales et autonomes utilisées pour habiller le portfolio.

- [`banner.svg`](banner.svg) — bannière décorative large.
- [`mark.svg`](mark.svg) — marque compacte.
- [Charte visuelle](../../docs/CHARTE_VISUELLE.md) — couleurs, principes et règles d’usage.

Les visuels ne représentent pas une accréditation, un outil opérationnel ou une affiliation à une organisation tierce.
