# Identité TheMadDoG.tmdg

Illustrations vectorielles originales et autonomes utilisées pour habiller le portfolio et sa documentation.

- [`banner.svg`](banner.svg) — bannière décorative large.
- [`mark.svg`](mark.svg) — marque compacte.
- [Charte visuelle](../../docs/CHARTE_VISUELLE.md) — palettes complémentaires et règles d’usage.
- [Site web](https://teremuhamblin.github.io/README/) — interface principale.

La page web racine `index.html` utilise une palette violet/noir distincte, précisée dans la charte. Les images du dossier brand en sont une déclinaison visuelle complémentaire. Ces illustrations ne représentent pas une accréditation, un outil opérationnel ou une affiliation à une organisation tierce.
