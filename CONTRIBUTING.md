# Contribution au portfolio

Merci de contribuer à rendre ce portfolio plus clair, accessible et vérifiable.

## Contributions bienvenues

- Corrections typographiques ou de liens.
- Améliorations de navigation et de lisibilité.
- Documentation de projets avec un périmètre et un statut exacts.
- Visuels originaux, légers, accessibles et autorisés à la publication.
- Améliorations de l’accessibilité et de l’affichage mobile.

## Avant d’ouvrir une pull request

- [ ] La modification est liée au contenu public du portfolio.
- [ ] Aucun secret, identifiant, donnée personnelle ou information confidentielle n’est ajouté.
- [ ] Les références et affirmations sont vérifiables et autorisées à la publication.
- [ ] Les images disposent d’un texte alternatif si elles transmettent une information.
- [ ] Les liens relatifs fonctionnent depuis GitHub.
- [ ] La documentation et `structure.md` sont mises à jour si l’arborescence change.

## Proposer une modification

1. Décrivez le problème ou l’amélioration souhaitée.
2. Indiquez les fichiers concernés et l’effet attendu.
3. Pour les visuels, précisez leur origine et leur licence ou confirmez qu’ils ont été créés pour ce projet.
4. Soumettez une pull request avec un résumé clair.

Ne publiez jamais de détails confidentiels dans une issue ou une pull request. Pour les signalements sensibles, suivez les consignes de [`docs/SECURITE.md`](docs/SECURITE.md).
