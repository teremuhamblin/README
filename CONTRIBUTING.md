# Contribution au portfolio

Merci de contribuer à rendre le site et sa documentation plus clairs, accessibles et vérifiables. La page principale est [`index.html`](index.html) ; le [`README.md`](README.md) en est le résumé pour GitHub.

## Contributions bienvenues

- Corrections de liens, de contenu ou de cohérence entre le site et les documents.
- Améliorations d’accessibilité, de navigation et de responsive design.
- Documentation de projets avec périmètre autorisé, statut exact et références vérifiables.
- Visuels originaux légers, accessibles et autorisés à la publication.

## Avant une pull request

- [ ] La modification est liée au contenu public du portfolio.
- [ ] Aucun secret, identifiant, donnée personnelle ou information confidentielle n’est ajouté.
- [ ] Les références et affirmations sont vérifiables et autorisées à la publication.
- [ ] Les ancres HTML, liens Markdown et appels à l’action ont des destinations valides.
- [ ] Le site reste utilisable au clavier, sur mobile et avec la réduction de mouvement.
- [ ] Les images informatives possèdent un texte alternatif.
- [ ] Le README, les fiches projets et la documentation restent cohérents avec `index.html`.
- [ ] `structure.md` est actualisé si l’arborescence change.

## Proposer une modification

1. Décrivez le problème ou l’amélioration souhaitée.
2. Indiquez les fichiers concernés et l’effet attendu.
3. Pour les visuels, précisez leur origine et leur licence ou confirmez qu’ils ont été créés pour ce projet.
4. Soumettez une pull request avec un résumé clair et les vérifications réalisées.

Ne publiez jamais de détails confidentiels dans une issue ou une pull request. Pour les signalements sensibles, suivez les consignes de [`docs/SECURITE.md`](docs/SECURITE.md).
